### Gemini 的 debug 建议
#### ❌ 错误 1: 错误的指标和函数 (`np.avg` 和除法)

- **问题：**
    
    - 你在计算 `(y_real - y_pred) / y_real`，这是 **MAPE (平均绝对百分比误差)** 的一部分，**不是 MAE (平均绝对误差)**。
        
    - `np.avg` 不是一个标准函数，应为 `np.mean` 或 `np.average`。
        
- **修正：**
    
    - 如果目标是 **MAE**：应计算 `np.abs(y_real - y_pred)`。
        
    - 如果目标是 **MAPE**：应该使用 `y_true` 作为分母（但你的 MAPE 逻辑在循环中是错误的）。
        

#### ❌ 错误 2: 循环维度错误和效率低下 (最致命)

你试图逐个样本进行预测和累加，这在 Python 中是效率极低的，而且会导致维度错误：

- **`for i in range (len(X_test)):`**：循环本身是多余的。
    
- **`model.predict(X_test[i])`**：`X_test[i]` 是一个**一维数组**（一行特征），但 `model.predict()` 期望的是**二维数组**（`[1个样本, n个特征]`）。这通常会导致 `ValueError`。
    
- **`mae_curr = 0`**：每次循环都被重置，导致你最终返回的只是**最后一个样本的错误**。

### 1 更正道:

from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error 

def poly3(X_train, y_train, X_test, y_test):
    
    model = LinearRegression()
    model.fit(X_train, y_train)
    
    y_pred = model.predict(X_test)
    
    mae = mean_absolute_error(y_test, y_pred) 
    
    return mae
