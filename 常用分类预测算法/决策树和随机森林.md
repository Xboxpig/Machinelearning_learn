
除了支持向量机和 kNN 之外，决策树和随机森林也是非常不错的分类方法。如果你没有听说过随机森林，就把它当作是用决策树组成的森林就好了。所以这里，我们会将两种方法放在一起介绍。

# 决策树

决策树理解起来非常简单，义务教育阶段其实就已经接触过决策树的概念了。在决策分析中，我们可以用一棵决策树可以形象地展示决策过程，而决策树中，就类似于 if-then 规则的集合。例如，我们用下面的决策树来区分西瓜的好与坏：

执行决策树算法，一般分为三步：
### 第一步：特征选项。

特性选择及选择判断规则。
*例如上面判断西瓜好坏的决策树中，我们的特征为触感、敲声。*
特征选择是决策树建立前完成的工作，它决定了决策树的最终形状。
一般情况下，我们依据 3 种指标来选择特征，分别是**信息增益**、**信息增益比**、以及**基尼指数**。

*其中，依据信息增益来选择特征，是一种来源于信息论和概率统计中的方法。我们通过判断某一特征对决策树前后影响的信息差值，从而选出最关键的特征。这种依据信息增益来选择特征的算法，也被称作 ID3 算法。

*后来，我们发现信息增益在划分训练数据特征时，容易偏向取值较多的特征。于是，我们改进了 ID3 算法，通过信息增益比值来选择，发展出了 C4.5 算法。除此之外，还有一种叫 CART 的生成算法，它利用了基尼指数最小化的原则。

### 第二步：树的生成。

选择完特征之后，我们就通过这些特征来生成一颗完整的决策树。生成的原则是，所有训练数据都能分配到相应的叶节点。

### 第三步：树的剪枝。

一颗完整的决策树，使得训练数据得到有效的划分。但是，你会发现完整的决策树往往对于测试数据的效果并不好。这就出现了过度拟合的问题。

**过度拟合**，指模型对训练数据的效果很好，但是对测试数据的效果差，泛化能力较弱。

解决决策树过度拟合的方法是对决策树进行**剪枝**。
剪枝，也就是去掉一些叶节点。剪枝并不是随意乱剪，它的依据是，剪枝前和剪枝后的决策树整体损失函数最小。

对于决策树的演示，我们用到了著名的鸢尾花 IRIS 数据集。

IRIS 是机器学习领域一个非常经典的分类数据集，它总共包含 150 行数据。每一行数据由 4 个特征值及一个目标值组成。其中 4 个特征值分别为：萼片长度、萼片宽度、花瓣长度、花瓣宽度。而目标值及为三种不同类别的鸢尾花，分别为：IRIS Setosa，IRIS Versicolour，IRIS Virginica。

IRIS 数据集无需导入 CSV 文件，作为常用的基准数据集之一，scikit-learn 提供了相应的导入方法。

## 构建代码

```
from sklearn import datasets

# 载入数据集
iris = datasets.load_iris()
iris.data, iris.target 
```
#### Q: 它是数据的什么属性？
A:
`iris.target` 代表了 Iris 花朵的**种类 (Species)**。

- **数据内容：** 它是一个一维数组（向量），里面只包含数字 0、1 或 2。
- **0 对应：** Setosa（山鸢尾）
- **1 对应：** Versicolor（变色鸢尾）
- **2 对应：** Virginica（维吉尼亚鸢尾）

###接下来构建决策树模型

```from sklearn.tree import DecisionTreeClassifier

# 建立模型
model = DecisionTreeClassifier()
# 模型训练
model.fit(iris.data, iris.target)
```

你看到的输出是这棵决策树模型的**超参数 (Hyperparameters)** 列表。

#### Q1. 什么是超参数？

在机器学习中，我们区分两种参数：

- **模型参数 (Parameters)：** 模型在 `model.fit()` 训练过程中**自己学习**和确定的值（例如，决策树中的实际**分割点**和**分割规则**）。这些不会显示在这个输出中。
	
- **超参数 (Hyperparameters)：** 这是你在开始训练之前，**手动设定**的“模型配置”或“学习限制”。由于你没有给 `DecisionTreeClassifier()` 传递任何参数，所以输出显示的是 scikit-learn 为所有设置提供的**默认值**。

这些参数定义了这棵树将如何生长、如何做决策以及在何处停止。

| **属性名称**                | **默认值**  | **作用和含义**                                                                                   |
| ----------------------- | -------- | ------------------------------------------------------------------------------------------- |
| **`criterion`**         | `'gini'` | **分裂标准 (Metric)**。决定了决策树在选择特征时，如何量化“信息增益”或“不纯度”。`gini` (基尼不纯度) 和 `entropy` (信息熵) 是最常见的两个选项。 |
| **`splitter`**          | `'best'` | **分裂策略**。指定在节点中如何寻找最佳分裂点。`'best'` 会穷尽所有特征来寻找最佳分裂。                                           |
| **`max_depth`**         | `None`   | **最大深度**。限制树可以向下生长的最大层数。`None` 意味着树会持续生长，直到所有叶子节点都是“纯的”（只包含一类样本），或者达到其他限制。                  |
| **`min_samples_split`** | `2`      | **最小分裂样本数**。一个节点必须包含至少多少个样本才能被允许进行分裂。默认值 2 意味着任何包含 2 个或更多样本的节点都可以尝试分裂。                      |
| **`min_samples_leaf`**  | `1`      | **最小叶子样本数**。一个叶子节点（树的末端）必须包含的最少样本数。这有助于防止模型过拟合 (Overfitting)。                               |
| **`random_state`**      | `None`   | **随机数种子**。如果设置一个固定数字（如 `42`），可以确保模型在每次运行时都以相同的方式做出随机选择，保证结果的可重复性。                           |

#### Q2.训练模型的本质为何?
`model.fit()` 的本质就是一个**贪心算法 (Greedy Algorithm)**：在树生长的每一步，它只考虑**当前**能找到的**最佳局部分割**，最终通过不断地局部优化，构建出一个完整的决策树结构。
##### Q2.1 贪心算法是什么?
一种算法策略，它在解决问题时，总是做出当前看起来**最好的、最有利的选择**。
###### 核心思想：只看眼前利益
贪心算法的决策是基于**局部信息**的，它不考虑将来的后果，也不需要回顾过去。
- **目标：** 希望通过一系列的局部最优选择，最终能达到全局的最优解。
- **策略：** “在每一步都选择最大的甜头。”
###### 经典的“爬山”比喻
想象你在浓雾中爬山，你的目标是山顶：

- **贪心策略：** 你只能看到周围几米，所以每走一步，你都选择**坡度最陡、最高**的方向。
- **结果：**
    
    - **成功**：如果山形很规则，一直往上走确实能到山顶。
    - **失败**：如果最陡峭的路走几步后是一个**悬崖**（局部最优解），你就无法到达真正的山顶（全局最优解）。

###### 为什么说决策树是贪心的？


决策树在训练时，它选择特征和分割点的过程就是一个经典的贪心算法：

1. **目标：** 在当前节点，找到能让不纯度下降**最大**的分界线。
    
2. **短视之处：** 决策树只计算**当前这一个分割**所能带来的收益（信息增益），它**不会**预先计算“如果我现在选择了一个略差的分裂，会不会在后面的三层带来更好的整体分类效果？”
    
3. **结论：** 它只顾眼前的最大利益（最大信息增益），所以是贪心的。
###### 总结：什么时候能用？
贪心算法之所以被使用，是因为它通常**简单、高效、速度快**。

- **适用场景：** 当问题的结构保证了**局部的最优选择**（眼前的最大甜头）**永远不会妨碍**你达到**全局的最优结果**时，贪心算法就能成功。（比如：超市找零钱，你总是给顾客最大的面额，一定能最快找完。）
	
- **不适用场景：** 当问题的每一步选择都会影响到后续的更大收益时，贪心算法就会失败。（比如：下象棋，如果只顾吃子而忽略了布局，必然输掉全局。）

# 随机森林

随机森林与决策树不同的地方在用，它不只是建立一颗树，而是建立一堆树。与决策树不同，随机森林每次只从全部数据集中随机抽取一部分数据用于生成树。另外，随机森林在生成树的时候不会剪枝。

随机森林的优点多多，例如：
- 它可以处理大量的数据；
- 它可以在特征不均衡时，依然维持较高的准确度；
- 随机森林学习速度快，一般情况下，结果比单纯应用决策树要好。
```
from sklearn.ensemble import RandomForestClassifier

X_train = iris.data[:120]
X_test = iris.data[120:]

y_train = iris.target[:120]
y_test = iris.target[120:]

# 建立模型
model_tree = DecisionTreeClassifier(random_state=10) #决策树模型
model_random = RandomForestClassifier(random_state=10, n_estimators=10) #随机森林模型

# 训练模型并验证
model_tree.fit(X_train, y_train)
s1 = model_tree.score(X_test, y_test)

model_random.fit(X_train, y_train)
s2 = model_random.score(X_test, y_test)

print('DecisionTree:', s1)
print('RandomForest:', s2)
```
Out:
```
DecisionTree: 0.7333333333333333
RandomForest: 0.8333333333333334
```
